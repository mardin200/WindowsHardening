# Security Policy

## Supported Versions

The current `main` branch is the primary supported version of this project.

Older versions may not receive security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues.

When GitHub's private vulnerability reporting feature is available for this repository, please use it to submit a confidential report through the repository's **Security** tab.

If private vulnerability reporting is unavailable, please contact the repository owner through GitHub and provide the following information:

* A clear description of the vulnerability
* Steps to reproduce the issue
* Affected component or file
* Potential security impact
* Any relevant proof-of-concept or technical details

Please avoid publicly disclosing the vulnerability before a fix or mitigation has been prepared.

## Response

Security reports will be reviewed and, when appropriate, addressed through a software update, mitigation, or documented recommendation.

Response and remediation timelines may vary depending on the severity and complexity of the reported issue.

## Scope

This policy covers security vulnerabilities in the WindowsHardening project itself.

The project is intended to perform read-only Windows security hardening assessments. Its current implementation does not intentionally modify Windows services, firewall configuration, registry settings, user accounts, group membership, or security policies.
